Linux Crontab command to potężne narzędzie służące do planowania i automatyzacji zadań w uniksowych systemach operacyjnych.

W tej misji Państwa zadaniem jest przeanalizowanie wyrażenia czasowego crontab (format crontab MIN HOUR DOM MON DOW), zwrócenie posortowanej rosnąco listy następnych 3 czasów wykonania na podstawie podanej bieżącej daty (format ISO YYYY-MM-DDTHH:MM).

Państwa skrypt musi obsługiwać wszystkie standardowe wyrażenia crontab:

  • Pojedyncze liczby: 5, 10, 15;
  • Zakresy: 1-5;
  • Kroki: */2, 1-10/2;
  • Listy: 1,3,5;
  • Znak specjalny: *;
  • Specjalne słowa kluczowe: @rocznie (@annually), @miesięcznie (@monthly), @tygodniowo (@weekly), @codziennie (@midnight), @godzinowo (@hourly).
